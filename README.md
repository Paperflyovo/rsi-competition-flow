# 参赛调研台

为独立开发者和小团队整理智能体、AI 应用和游戏开发的参赛机会。在画布里选择主办方公告、提取参赛条件、核对原文，把值得继续关注的比赛导出为清单。

## 本地使用

使用 Node.js 22.12 或以上版本及 pnpm 11，在项目根目录运行以下命令。

~~~powershell
pnpm install --frozen-lockfile
pnpm research
~~~

打开 [本地参赛调研台](http://127.0.0.1:3210/competitions)。首页也会进入调研台。

### 离线查看与分流

点击「查看赛事快照」可以直接阅读 8 场比赛的状态、日程和原文。快照采集于北京时间 2026 年 11 月 21 日，日期和状态按采集当天展示。[赛事快照](public/data/competition-snapshot.json)

要试画布，选择「新建 / 模板」里的「历史赛事分流」，勾选三个方向，点击「运行历史数据流程」。示例会把当时已截止的 1 场比赛与其余 7 场分开。点击条件节点，将状态改成「开放投稿」再运行，两份清单会变为 3 场和 5 场。快照流程在本机运行，模型调用次数为零。

### 实时调研与个人模型

选择「实时赛事调研」，在「运行设置 → 模型服务」中选择自己的服务、模型和 API Key，然后点击「运行实时调研」。程序重新读取所选方向的主办方公告，把公告交给所选模型，核对资格和作品要求的原文摘录，区分报名、交件和颁奖日期。实时模型请求可能产生费用。手动输入的密钥只保存在当前页面内存中。

如需使用「服务端默认」，在项目根目录的本机 `.env.local` 中设置 `COMPETITION_LLM_BASE_URL`、`COMPETITION_LLM_MODEL` 和 `COMPETITION_LLM_API_KEY`，之后重新启动调研台。`.env.local` 已由 Git 忽略。

## 编辑流程

用「添加节点」放置第一步。可以把输出端口拖到同色输入端口，也可以拖到空白处，选择下一个节点。点击连线可插入节点或断开连接。拖动空白处平移，滚轮和加减按钮可缩放。用「校验」定位无效连线、缺失输入或环路，用「撤销」恢复修改。正在运行时可以停止，在结果区查看各节点的输入、输出和失败原因。

浏览器会保存编辑草稿。「导出」保存流程定义，「导入」恢复已有的流程 JSON。「下载本次记录」另外包含实际执行顺序、清单、运行轨迹及模型调用信息。

## 代码入口

- [画布编辑器](app/flow-editor/editor.jsx) 管理节点、连线、撤销、导入和导出。[画布绘制](app/flow-editor/diagram.jsx) 在浏览器中绘制节点和连线，并处理选取、拖动与缩放。
- [流程校验](src/research/graph.mjs) 检查端口、依赖和环路。[执行器](src/research/run.mjs) 按依赖顺序执行节点，每次运行单独保存各输出端口的数据。
- [节点行为](src/research/operations.mjs) 实现采集、提取、核验、分流和合并。[赛事来源](src/research/sources.mjs) 维护主办方入口和日程解析，[模型接入](src/research/model.mjs) 读取配置并校验摘录。
